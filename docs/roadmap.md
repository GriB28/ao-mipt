# Порядок работ

Задачи отсортированы по принципу «что сломает олимпиаду, если не успеем».
Оценки — в человеко-днях для одного человека, знакомого с Django.

Исходные условия: до тысячи участников, дистанционный этап длится несколько
месяцев, проверка задач ручная, хостинг предоставляет МФТИ. Из этого следует,
что нагрузочные задачи и автопроверка ушли далеко вниз, а на первое место
вышли согласования, которые идут дольше разработки.

## Возможное развитие

* **Автопроверка задач по программированию.** Отложена сознательно: на первый
  сезон проверка ручная. Запуск кода участника в изолированном контейнере с
  лимитами по времени и памяти — 5–10 дней работы и заметный риск по
  безопасности. Браться, когда ручная проверка станет узким местом.
* **Темы задач и поиск по ним** в архиве — школьники ищут «задачи на орбиты»,
  а не «задача 4 за 2023 год». Одно поле и один фильтр, полдня.
* **Telegram-бот** для уведомлений: у вас уже есть опыт с ботами, а школьники
  читают Telegram охотнее почты.
* **Вход через Госуслуги/Сферум**, если потребуется подтверждение личности.
