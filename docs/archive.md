# Архив прошлых лет

Разбор содержимого вашей папки на Яндекс.Диске и план, как превратить её
в удобный раздел сайта.

## Что лежит в архиве

12 папок по турам плюс два файла в корне. Всего 83 файла, около 1,8 ГБ.

| Закл2021 | 2 | PDF с заданиями, данные |
| Отбор2021 | 1 | PDF с заданиями |
| Закл2022 | 2 | только данные (.csv), условий нет |
| Отбор2022 | 2 | PDF заданий + **видеоразбор 1,6 ГБ** |

## Три находки, которые важны

### 1. Нумерация папок сдвинута относительно сезонов

Папки названы по **календарному году тура**, а сезон олимпиады идёт через
два года: отбор осенью, финал весной. То есть:

```
Отбор2023  +  Закл2024   =  один сезон, АО IV
Отбор2025  +  Закл2026   =  один сезон, АО VI
```

Если импортировать «в лоб» по числу в названии папки, архив развалится на
половинки сезонов: отбор АО IV попадёт в один год, а его же финал — в другой.
В команде импорта это учтено, сезон называется по году финала. Гипотеза
проверена по содержимому: `aoIV.pdf` действительно лежит в `Отбор2023`,
а `решения_AO_V_сезон.pdf` — в `Отбор2024`.

### 2. Структура папок неоднородна

Три разных способа организации за шесть лет:

* один общий PDF на весь тур (Отбор2021, Отбор2023);
* отдельно теория и практика (Закл2024, Закл2026);
* разложено по папкам «N задача» (Закл2023).

А в Закл2022 лежат только данные — условий нет вовсе.

Вывод: **привести всё к единому «по задачам» автоматически невозможно.**
Условия сидят внутри общих PDF, и разрезать их может только человек.

### 3. Два файла весят больше, чем всё остальное вместе

`Разбор.mp4` — 1,6 ГБ и `sun_data.zip` — 140 МБ. Это 96% объёма архива.
Класть их в хранилище сайта не нужно: видео место на VK Видео или YouTube,
большой архив данных может остаться на Яндекс.Диске со ссылкой.
Без них весь архив — около 60 МБ, что размещается без разговоров о дисковом
пространстве.

## Как это сделано на сайте

Два слоя, которые дополняют друг друга.

**Слой 1 — материалы тура (`ArchiveMaterial`).** Всё как есть: общий PDF
условий, PDF разборов, данные, код, видео. Привязано к сезону и этапу,
размечено по типу. Публикуется сразу, без ручной работы.

**Слой 2 — задачи (`Problem`).** Отдельная задача с названием, условием и
разбором. Заполняется руками, постепенно, по мере того как доходят руки.

Страница `/problems/` показывает оба слоя: сначала разобранные задачи,
если они есть, потом материалы тура целиком. Архив полезен с первого дня,
а качество растёт со временем.

## Импорт

```bash
# посмотреть план, ничего не меняя
python manage.py import_archive --dry-run

# импортировать: файлы скачиваются к нам, кроме тех, что больше 50 МБ
python manage.py import_archive

# только ссылки, ничего не скачивать
python manage.py import_archive --no-download
```

**Файлы скачиваются по умолчанию.** Это осознанный выбор: архив не должен
зависеть от того, жива ли чужая папка на Яндекс.Диске и не поменялась ли
у неё ссылка. Всё, что меньше 50 МБ, лежит у нас и отдаётся прямо с сайта.

Для крупных файлов (видеоразбор 1,6 ГБ, `sun_data.zip` на 140 МБ) остаётся
ссылка на Яндекс.Диск. Важно: она ведёт **на конкретный файл**, а не на
общую папку — Яндекс.Диск понимает адрес вида
`<публичная ссылка>/<путь внутри папки>`. Человеку не приходится искать
нужный файл среди двенадцати папок.

На странице архива такие материалы помечены плашкой «на Яндекс.Диске»,
чтобы было видно, что ссылка уводит с сайта.

Команда идемпотентна: материал опознаётся по пути в исходном архиве,
повторный запуск ничего не задвоит. Уже проверено — второй прогон дал
«создано: 0, обновлено: 83».

Импорт разложил 83 файла по шести сезонам и определил тип каждого:
35 файлов с данными, 27 с кодом, 12 условий, 7 разборов, видео и результаты.
Ошибки разметки правятся в админке (Контент → Материалы архива).

## Что делать дальше — по порядку

1. **Запустить импорт** (20 минут): `python manage.py import_archive`.
   Файлы переедут на сайт, архив станет доступен по годам.
2. **Залить видеоразбор во ВКонтакте**, ссылку вписать в материал (10 минут).
3. **Проверить и поправить разметку** в админке (час). Особенно типы
   материалов из Отбор2020 — там учебные ноутбуки по Python, а не задачи.
   Их логичнее перенести в раздел лекций.
4. **Разобрать по задачам** — постепенно, сезон за сезоном. Начать стоит
   с последних двух: их спрашивают чаще всего.
5. **Добавить два исторических файла** (1990 и 2008 год) вручную — они
   лежат в корне вне структуры сезонов. Для них стоит завести отдельный
   раздел «История олимпиады»: это не наши сезоны, а предшественники.

## Про поиск по задачам

Вы спрашивали про доступ «по годам / турам / задачам». Первые два работают
сразу. Поиск по задачам осмысленно делать только после шага 4 — пока
условия лежат внутри общих PDF, искать нечего.

Когда до этого дойдёт, стоит добавить задачам **темы** (механика, оптика,
орбиты, обработка сигналов) — по опыту школьники ищут именно так:
«хочу порешать задачи на орбиты», а не «покажите задачу 4 за 2023 год».
Это одно поле и один фильтр, полдня работы.

## Чего делать не стоит

**Автоматически резать PDF на задачи.** Попытка распознать границы задач
в вёрстке LaTeX даст мусор, который потом всё равно придётся вычищать
руками — дольше, чем сразу сделать вручную.

**Заливать видео в хранилище сайта.** 1,6 ГБ на каждое видео, отдача с
одного сервера, никакой адаптации качества под скорость соединения.
Видеохостинги делают это лучше и бесплатно.
