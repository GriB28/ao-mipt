# Оформление сайта — инструкция для дизайнера

## Главное

**Весь визуальный язык сайта живёт в одном файле: `static/css/tokens.css`.**

Поменяли значение там — изменился весь сайт. Править шаблоны, `main.css` или
Python-код не нужно и не следует. В `main.css` нет ни одного цвета в виде
`#hex` — только ссылки на токены, и так должно остаться.

---

## Текущая палитра

Она не придумана с нуля: цвета сняты со свотча `pings/цвета.svg`, который
пришёл вместе с маскотом — пингвином. Это тот самый тёмно-синий космос
с лавандовым пингвином и тёплыми оранжевыми лапками.

| Токен | Цвет | Где применяется |
|---|---|---|
| `--color-space-900` | `#0d2050` | фон шапки, подвала, обложки героя |
| `--color-space-700` | `#0a1a58` | второй цвет градиента героя |
| `--color-brand-500` | `#2b5e96` | **основной акцент**: кнопки, ссылки |
| `--color-brand-600` | `#1c3e79` | наведение на кнопку |
| `--color-lavender-400` | `#8796da` | тело маскота; акценты на тёмном фоне |
| `--color-lavender-200` | `#bdc5eb` | вторичный текст на тёмном |
| `--color-accent-500` | `#f88d41` | тёплый акцент (лапки пингвина), точечно |
| `--color-accent-700` | `#b54f07` | тот же акцент, но для текста — `accent-500` не проходит контраст 4.5 |
| `--color-mascot-shadow` | `#915354` | справочный цвет маскота (тень клюва/лап); в интерфейсе не используется — третий акцент был бы перебором |
| `--color-ink-900` | `#10142b` | основной текст |
| `--color-surface` | `#f6f1ef` | подложки карточек — тёплый кремовый |

Логика: **тёмный космос в шапке, подвале и герое; светлый фон в основной
части.** Условия задач читают долго, и тёмная тема на всю страницу тут
мешает. Космос остаётся обрамлением, как на баннерах.

**Градиенты.** Шапка, подвал, герой, кнопки и схема этапов залиты
градиентами — все они собраны в `tokens.css` в разделе «Градиенты» и
идут только между соседними цветами палитры. Фирменная полоса
`--gradient-stripe` (оранжевый → лавандовый → синий) отделяет шапку и
подвал от светлой части.

**Оранжевый акцент** — по-прежнему точечно: кнопка регистрации (одна на
экран, `.btn-accent`, тёмный текст — белый на оранжевом не проходит
контраст), черта под заголовком страницы, активный пункт меню, стрелки
и карточка финала на схеме этапов, сроки в герое.

Если свотч `pings/цвета.svg` обновится (новая версия маскота или новый
сезон) — пересчитать контраст по инструкции ниже и обновить эту таблицу
вместе с `tokens.css`.

## Структура файла токенов

```
ФИРМЕННЫЕ ЦВЕТА     сырая палитра         --color-brand-500
СЕМАНТИЧЕСКИЕ       назначение цвета      --button-bg: var(--color-brand-500)
ТИПОГРАФИКА         шрифты и размеры      --font-sans, --text-2xl
РАЗМЕРЫ             отступы, радиусы      --space-4, --radius-md
```

Шаблоны используют **семантические** токены, а не сырые цвета. Благодаря
этому можно перекрасить, например, только кнопки, не трогая всю палитру:
достаточно поменять `--button-bg`.

## Контраст — обязательное требование

Олимпиадой пользуются с телефонов, в школьных классах, на проекторах.
Любая пара «текст на фоне» должна давать коэффициент контраста **не ниже
4.5** (для крупного текста и элементов интерфейса — 3.0). Это стандарт
WCAG AA.

Текущая палитра проверена, все пары проходят. Проверить после правки:

```bash
.venv/bin/python - <<'PY'
def lum(h):
    h = h.lstrip('#'); c = [int(h[i:i+2],16)/255 for i in (0,2,4)]
    c = [x/12.92 if x <= 0.04045 else ((x+0.055)/1.055)**2.4 for x in c]
    return 0.2126*c[0] + 0.7152*c[1] + 0.0722*c[2]
def ratio(a, b):
    la, lb = lum(a), lum(b)
    return (max(la,lb)+0.05) / (min(la,lb)+0.05)

print(round(ratio("#2b5e96", "#ffffff"), 2))   # ссылка на белом фоне
PY
```

Отдельная ловушка: **при наведении кнопку нужно затемнять, а не осветлять.**
Осветление уронило контраст белого текста до 3.47 — поэтому
`--button-bg-hover` темнее основного цвета, а не светлее.

## Цвет сезона

У каждого сезона в админке есть поле «цвет сезона». Оно подменяет
`--color-brand-500` на всём сайте — так оформление меняется под сезон
без правки кода и без участия дизайнера.

Если сезону нужен не только другой акцент, а другая палитра целиком —
это правка `tokens.css`.

## Подключение фирменного шрифта

1. Добавить строку загрузки шрифта в `templates/base.html`, в блок `{% block head %}`.
2. Поменять `--font-sans` (и при желании `--font-display` для заголовков)
   в `tokens.css`.

Шрифт лучше положить в `static/fonts/` и раздавать со своего сервера, а не
подключать со сторонних CDN: иностранные CDN могут быть недоступны.

## Логотип

Логотип сезона загружается **в админке** (Сезоны → Сезон → логотип) и
автоматически появляется в шапке рядом с названием. Отдельно в код его
класть не нужно.

Для шапки нужна версия на прозрачном фоне: фон там тёмно-синий.
Текущий `лого.png` — с белым кругом, он подойдёт, но версия без подложки
будет смотреться аккуратнее.

## Маскот

У олимпиады появился маскот-пингвин (`pings/*.svg`) — используется в
`static/img/mascot/`: герой на главной, favicon, часть пустых
состояний. Что уже сделано, что дорисовать и в чём проблема с одним
из файлов — подробное ТЗ в `docs/mascot-tz.md`, не дублирую его здесь.

Перечислено по убыванию пользы. Пункты про маскота (3, 5 частично, 6) —
подробнее в `docs/mascot-tz.md`.

1. **Логотип на прозрачном фоне** для шапки, высота 34px.

5. **Пустые состояния**: «задачи появятся позже», «вы ещё ничего не сдали» —

   для такого размера слишком детальная. Три из пяти пустых состояний
   (новости, лекции, архив) маскот уже получил.
6. **Декоративные элементы** с баннеров — звёздочки, планета с кольцом —
   как фон героя и материал для будущей обложки соцсетей.

## Чего делать не надо

* Не добавляйте цвета мимо `tokens.css` — через сезон никто не найдёт,
  откуда взялся конкретный оттенок.
* Не используйте оранжевый акцент часто: он работает, пока его мало.
* Не делайте текст условий шире `--content-width` (720px) — длинные строки
  тяжело читать.
