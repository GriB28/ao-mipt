# Как запустить сайт у себя — с нуля, по шагам

Инструкция для человека, который **не работал ни с git, ни с Python, ни с
Django**. Ничего знать заранее не нужно. Всё, что здесь написано, делается
один раз и занимает минут пятнадцать, большую часть из которых компьютер
качает файлы.

Сайт запустится **только на вашем компьютере**. Никто снаружи его не
увидит, сломать ничего нельзя: все данные учебные и лежат в одном файле,
который можно удалить и создать заново.

---

## Что такое «терминал» и как его открыть

Терминал — окно, куда пишут команды текстом вместо того, чтобы кликать
мышкой. Команды из этой инструкции нужно **копировать и вставлять**, а
потом нажимать Enter.

* **Windows:** нажмите `Пуск`, наберите `PowerShell`, откройте
  «Windows PowerShell».
* **macOS:** `Cmd + Пробел`, наберите `Терминал`, Enter.
* **Linux:** `Ctrl + Alt + T`.

Дальше в инструкции строчки вида

```bash
что-то напечатать
```

— это и есть команды. Вставляйте их целиком, по одной.

## Шаг 1. Поставить две программы

Нужны **git** (скачивает и обновляет код) и **Python** (на нём написан
сайт). Проверьте, может, они уже стоят:

```bash
git --version
python3 --version
```

Если в ответ печатаются номера версий вроде `git version 2.43` и
`Python 3.12` — всё есть, переходите к шагу 2. Нужен Python **3.12 или
новее**; если версия младше, поставьте свежий.

Если пишет «команда не найдена»:

* **Windows:** скачайте [git](https://git-scm.com/download/win) и
  [Python](https://www.python.org/downloads/). В установщике Python
  обязательно отметьте галочку **«Add Python to PATH»** — без неё
  компьютер не найдёт Python. После установки закройте терминал и
  откройте заново.
* **macOS:** выполните `xcode-select --install` — поставится git.
  Python скачайте с [python.org](https://www.python.org/downloads/).
* **Linux (Ubuntu/Debian):**
  ```bash
  sudo apt update && sudo apt install -y git python3 python3-venv make
  ```

На Windows вместо `python3` пишите `python` — дальше в инструкции это
отмечено.

## Шаг 2. Скачать код

Выберите папку, где будет лежать проект, например «Документы»:

```bash
cd ~/Documents
git clone https://github.com/leeiozh/ao-mipt.git
cd ao-mipt
```

`git clone` скачивает проект целиком. Появится папка `ao-mipt` — вы уже
внутри неё.

Если git спросит логин и пароль — значит, репозиторий закрытый; попросите
доступ у Лизы.

---

## Шаг 3. Запустить

### Если есть `make` (Linux и macOS)

Одна команда:

```bash
make start
```

Она поставит всё нужное, создаст базу с учебными данными и запустит сайт.

### Если `make` нет (обычно Windows)

Четыре команды по очереди:

```bash
python -m venv .venv
.venv\Scripts\pip install -r requirements-dev.txt
.venv\Scripts\python manage.py migrate
.venv\Scripts\python manage.py seed_demo
```

Ещё нужен файл настроек — скопируйте образец и включите режим разработки:

```bash
copy .env.example .env
```

Откройте `.env` блокнотом и замените строку `DEBUG=False` на `DEBUG=True`.
Больше там менять нечего.

Запуск:

```bash
.venv\Scripts\python manage.py runserver
```

## Шаг 4. Открыть сайт

В терминале появится строчка вроде

```text
Starting development server at http://127.0.0.1:8000/
```

Откройте в браузере **http://127.0.0.1:8000** — это и есть сайт.

**Терминал закрывать нельзя**, пока смотрите сайт: в нём работает сервер.
Чтобы остановить — `Ctrl + C` в терминале.

## Что можно спокойно делать

Всё. Данные учебные, чужих персональных данных в них нет, а база живёт в
одном файле `db.sqlite3` внутри папки проекта.

Если всё сломалось и хочется начать заново:

```bash
make clean
make migrate
make seed
```

или без `make`:

```bash
del db.sqlite3
.venv\Scripts\python manage.py migrate
.venv\Scripts\python manage.py seed_demo
```

## Что стоит потестировать

* **Зарегистрироваться школьником** и заполнить анкету: школа, город,
  регион из списка, телефон или телеграм.
* **Записаться на площадку** очного тура на карте и отменить запись.
* **Сдать решение** — на вкладке «Дистанционный тур» внизу есть
  тренировочная задача, она открыта всегда.
* **Проверить решение** организатором и выставить балл.
* **Завести задачу и лекцию** организатором, одобрить администратором.
* **Заполнить ведомость** площадки и опубликовать результаты.
* Посмотреть, **как сайт выглядит на телефоне** — сузьте окно браузера.

Письма (подтверждение почты, рассылки) никуда не уходят — они печатаются
прямо в терминал, где запущен сервер. Это нормально: почтовый сервер
локально не настроен, и ссылку из письма видно в том же окне.

## Как работать параллельно с другими

Чтобы не мешать друг другу, каждый делает правки в **своей ветке** —
отдельной копии кода внутри того же проекта.

```bash
git checkout -b моя-ветка
```

Дальше правьте что угодно. Сохранить свои изменения:

```bash
git add -A
git commit -m "что сделал"
git push -u origin моя-ветка
```

Забрать изменения других:

```bash
git checkout main
git pull
```

Если что-то пошло не так и хочется вернуть как было:

```bash
git checkout -- .
```

Эта команда стирает **несохранённые** правки — то, что уже попало в
`git commit`, она не трогает.

## Если не получилось

Частые случаи:

| Что пишет | Что делать |
|---|---|
| `python3: command not found` | Python не установлен или без «Add to PATH». Переустановите с галочкой |
| `git: command not found` | не установлен git, см. шаг 1 |
| `Port 8000 is already in use` | сайт уже запущен в другом окне. Закройте его или `runserver 8001` |
| `SECRET_KEY пуст, а DEBUG=False` | в `.env` не переключён `DEBUG=True` |
| `Invalid HTTP_HOST header` | то же самое: `DEBUG=True` в `.env` |
| Страница белая, в терминале красный текст | скопируйте **последние 20 строк** из терминала и пришлите — по ним видно причину |
