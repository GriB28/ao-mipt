{% comment %} Карта площадок. Два движка: Яндекс.Карты, если в .env задан YANDEX_MAPS_API_KEY, иначе OpenStreetMap через Leaflet (работает без ключа, но в некоторых сетях его тайлы недоступны). Данные в обоих случаях берутся из одного GeoJSON-эндпоинта, поэтому переключение движка не требует правок на сервере. Параметры включения: picker=True — режим выбора точки: клик ставит метку и заполняет скрытые поля формы с координатами (используется при добавлении площадки). В этом режиме Яндекс дополнительно определяет адрес по координатам и сверяет его с выбранным регионом — это ловит промах по карте. {% endcomment %}
