Официальный репозиторий веб-платформы [Аэрокосмической олимпиады МФТИ](https://ao.mipt.ru). 
Платформа обеспечивает полный цикл проведения олимпиады: онлайн-регистрацию участников, интерактивную карту и координацию региональных очных площадок, приём и проверку авторских междисциплинарных задач, публикацию лекций, ведение архива соревнований и подведение итогов.

---

## О проекте

**Аэрокосмическая олимпиада МФТИ** проводится ежегодно с 2020 года (в сезоне 2026/2027 проходит **VII сезон**). Организатором выступает [Физтех-школа аэрокосмических технологий (ФАКТ) МФТИ](https://fakt.mipt.ru) при поддержке Фонда целевого капитала МФТИ. Задачи составляют и олимпиаду проводят студенты, аспиранты и молодые учёные Физтеха.

Это не просто классическая олимпиада, а сезон погружения в современные аэрокосмические вызовы. В задачах нет готовых шаблонных формул: участники работают на стыке **физики, математики и программирования**, строят математические модели физических процессов (орбиты, динамика ракет, спутниковые системы, аэродинамика) и проверяют их аналитическими расчётами и алгоритмами.

### Олимпиада в цифрах

* **340+** участников за первые 6 сезонов
* **90+** финалистов, посетивших кампус МФТИ
* **88** уникальных авторских задач
* **≈ 1/3** финалистов прошлых сезонов поступили в МФТИ
* **20** бывших участников стали составителями задач и организаторами
* **100% бесплатно**: участие без организационных взносов для всех школьников 9–11 классов

### Структура и этапы сезона

Соревновательный сезон проходит с октября по апрель и состоит из двух ключевых туров:

1. **Отборочный тур** *(октябрь — январь, участник может выбрать любой формат или оба)*:
   * **Очный отборочный этап** — проходит на региональных площадках в школах и вузах-партнёрах по всей России.
   * **Дистанционный этап** — проходит онлайн на данной веб-платформе с решением задач в свободном темпе.
2. **Заключительный тур** *(для участников, преодолевших порог отбора)*:
   * **Второй тур (онлайн)** — проводится в единое фиксированное время с видеоконтролем и прокторингом.
   * **Финал (очный)** — заключительный тур на кампусе МФТИ в Долгопрудном: решение задач, лекции от ведущих учёных, встречи со студентами ФАКТ, экскурсии на передовые предприятия ракетно-космической отрасли, дипломы, призы и дополнительные баллы для поступления в МФТИ.

## Возможности платформы

Система спроектирована с учётом потребностей четырёх ключевых аудиторий:

* **Для школьников (участников 9–11 классов):**
  * Личный кабинет с авторизацией по e-mail и подтверждением почты.
  * Интерактивная карта площадок очного тура (Leaflet + OpenStreetMap) с фильтрацией по городам и онлайн-записью на площадку.
  * Сдача решений задач дистанционного этапа (файлы сканов, текстовые решения, архивные вложения), тренировочный контест для проверки загрузки.
  * Банк видеолекций и видеоразборов к каждой задаче текущего сезона.
  * Доступ к архиву задач и решений прошлых сезонов.
  * Личные результаты, баллы и ведомости после проверки.
  * Юридически выверенный контур согласий на обработку персональных данных (152-ФЗ) с генерацией печатных бланков.

* **Для региональных площадок (школ и вузов-партнёров):**
  * Подача заявок на открытие площадки и прохождение модерации оргкомитетом.
  * Панель организатора площадки: отслеживание записавшихся школьников, формирование списков.
  * Скачивание комплектов заданий в день тура, загрузка сканов выполненных работ для проверки жюри.

* **Для авторов задач и проверяющих (жюри):**
  * Создание задач в веб-интерфейсе с поддержкой формул в синтаксисе LaTeX, иллюстраций и критериев оценивания.
  * Двухэтапная модерация задач: подготовка организатором $\to$ утверждение администратором.
  * Очередь ручной проверки загруженных решений с выставлением баллов и комментариев.
  * Ведомости оценок и централизованная публикация результатов по площадкам.

* **Для оргкомитета и администраторов:**
  * Управление сезонами, этапами, расписанием и дедлайнами.
  * Сегментированные e-mail рассылки с очередью отправки (по сезонам, ролям, статусам участия).
  * Экспорт статического демо-сайта (`make demo`) для демонстрации партнёрам и публикации на GitHub Pages.

## Архитектура и стек технологий

Платформа рассчитана на стабильную работу с нагрузкой до нескольких тысяч участников, где ключевой приоритет — надёжность данных, безопасность персональных данных участников (152-ФЗ), удобство модерации и минимальная нагрузка на организаторов.

* **Бэкенд:** Python 3.12, Django 5.2 LTS, Django ORM.
* **База данных:** PostgreSQL 16 (production), SQLite 3 (локальная разработка и тесты).
* **Фронтенд:** серверный рендеринг (Django Templates), чистый семантический HTML5/CSS3 с дизайн-токенами (`tokens.css`), библиотека интерактивных карт **Leaflet** + подложка **OpenStreetMap**, рендеринг математических формул **LaTeX** (KaTeX/MathJax).
* **Безопасность и валидация:** `nh3` (санитизация HTML от XSS в условиях задач), валидация загружаемых файлов (MIME-types, ограничения размера), строгие права доступа (RBAC: участник / организатор / суперпользователь).
* **Документы и медиа:** `reportlab` (генерация бланков согласий на обработку ПД в PDF), `Pillow` (оптимизация и хранение изображений).
* **Инфраструктура и деплой:** Docker, Docker Compose, Nginx (раздача статики и обратный прокси), WhiteNoise, Gunicorn, автоматический контейнер регулярного резервного копирования БД в `backups/`.
* **Тестирование и качество кода:** Django Test Runner (более 210 тестов), Ruff (линтер и автоформаттер стандарта PEP 8).

Подробное обоснование архитектурных решений описано в [docs/architecture.md](docs/architecture.md).

## Структура репозитория

```
ao-mipt/
├── apps/                        # Модули приложения Django
│   ├── accounts/                # Модель пользователя (User по email), профили, согласия 152-ФЗ
│   ├── contest/                 # Задачи, отправка решений, критерии, очередь проверки, баллы
│   ├── content/                 # Новости, лекции, плейлисты, архив прошлых лет, статические страницы
│   ├── core/                    # Базовые модели, валидаторы файлов, навигация, общие тесты
│   ├── mailing/                 # Шаблоны рассылок, сегментация аудитории, очередь писем
│   ├── participation/           # Заявки на участие в сезоне, регистрация школьников
│   ├── seasons/                 # Сезоны олимпиады, этапы соревнований, дедлайны
│   └── venues/                  # Площадки очного тура, геокоординаты, модерация, запись участников
├── config/                      # Корневые настройки Django (settings.py, urls.py, wsgi.py)
├── deploy/                      # Конфигурации для сервера: Nginx, скрипты бэкапов и развёртывания
├── docs/                        # Подробная проектная и эксплуатационная документация
├── static/                      # Статические файлы (CSS токены, изображения, логотипы, скрипты)
├── templates/                   # Шаблоны страниц сайта (Django Templates)
├── docker-compose.yml           # Оркестрация контейнеров (веб-приложение, БД, Nginx, бэкапы)
├── Dockerfile                   # Многоэтапный Docker-образ приложения
├── Makefile                     # Утилиты автоматизации повседневных команд разработки
├── pyproject.toml               # Конфигурация линтера и форматтера Ruff
└── requirements.txt             # Зависимости Python для production-окружения
```
